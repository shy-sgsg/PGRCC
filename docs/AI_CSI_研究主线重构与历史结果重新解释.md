# AI-CSI 研究主线重构与历史结果重新解释

> 更新时间：2026-09-13。本文是当前研究阶段的导航和 framing 文档，不回写历史实验的输入、源码身份、原始数字或原有判定。

## 1. 当前研究问题

真实 airborne GMTI 系统并不保证 INS、伺服/波束指向、平台运动、通道时延、幅相、
时钟同步和阵列基线几何都已知且准确。它们会改变通道间的相位、幅度、时间轴、空间
导向矢量或杂波的慢时间统计，使原本可利用的多通道杂波相干性下降，进而影响 CSI、
四通道 STAP、CFAR、检测概率和目标保持。

当前主线因此固定为：

```text
真实系统未知误差
  → 多通道回波观测
  → 未知误差/状态参数估计
  → 物理模型修正与通道自校准
  → 恢复杂波通道相干性
  → CSI / 四通道 STAP 等杂波抑制
  → CFAR / Pd / Pfa / 目标保持评价
```

这里的 AI 不是终点。只有当多通道观测到误差/状态的映射难以用确定性模型充分
解析，且确定性估计已经有退化、真值恢复和残差证据时，才评估是否需要 AI 作为
估计器、残差或置信度模块。

## 2. 当前生产链

仓库需要始终把下面这条生产链作为 Current 的定义，而不是把某个抽象的理想信号
处理图当成生产实现：

```text
4-channel raw IQ
  → channel-pair fusion: (1,3), (2,4)
  → F1/F2
  → pulse compression
  → CTDR
  → DBS/Doppler
  → range phase correction
  → P38 phase model
  → CSI
  → production GO-CFAR
```

F1/F2 在 Current CSI 之前完成。四通道 STAP 则保留四个空间自由度。后续比较必须
同时提供两层结论：

1. **端到端能力层**：四通道原始 IQ 直接进入四通道 STAP，与 Current 的四通道协议
   IQ→F1/F2→CSI→GO-CFAR 全链路比较；
2. **信息量匹配层**：控制融合和空间自由度等信息条件后，单独比较算法、模型修正
   和协方差/导向矢量处理的贡献。

过去报告中“没有混入同一严格排名”是信息条件和汇报口径限制，不是“四通道 STAP
不能与两通道 CSI 比较”的研究结论。

## 3. 历史结果的统一解释

历史材料保留其原始术语，首次引用时按下表重新定位：

| 历史说法 | 当前解释 | 不能推出的结论 |
|---|---|---|
| Ideal Current / Oracle | 在指定数据、指定误差真值或背景 truth 下的已知误差校正上限（`Known-error correction upper bound`） | 不是无条件可实现的性能上界，也不是运行时可用的真值读取器 |
| Current–Oracle gap | 当前处理链与已知误差修正之间的可恢复空间候选 | 不能直接等同于可由估计器恢复的增益 |
| Mixed / OOD / M1/M2/M3 | 历史场景组合、分布外测试或具体误差机制标签 | 不是新的永久研究主线或通用 AI 训练任务 |
| `NO_GO_AI_FOR_NOW` / `FINAL_NO_GO_AI` | 针对当时候选 AI 形式、数据和门禁的阶段性不进入训练/部署 | 不否定未知系统误差可观测性、自校准或未来合适的 Physics-AI |
| `NO_GO_AI_ROUTER_VALUE` | Current/J5/J6 专家路由的安全平均材料性不足 | 不否定整个 Physics-AI 或未知系统误差估计方向 |
| J8 pulse-frequency / Clutter-Support-Only | 当前实现下的特定方法分支未进入主线 | 不否定平台、通道和杂波时间统计误差研究 |

新实验默认使用四个条件：

1. Ideal/No-error；
2. Current with unknown error；
3. Known-error correction upper bound；
4. Estimated-error correction。

对方向一致的指标，报告：

```text
recoverable space = Known − Current
actual recovered  = Estimated − Current
recovery ratio    = actual / recoverable
```

如果指标是“越小越好”（例如残余相位、杂波功率或虚警），必须在报告中先统一
符号再计算，不能把负差距裁剪成看似更好的结果。

## 4. 时间线：从 Current 残差走向未知系统误差

### 4.1 初始 Current 残差

最初工作先复现 Current，并用 Current–Oracle（当前术语）比较残差，目标是确认
问题存在、量化差距和找到失配位置。这个阶段没有训练 AI。

### 4.2 生产链审计与修复

随后核对协议通道、F1/F2 融合、脉压、CTDR、DBS/Doppler、距离相位修正、P38、CSI
和生产 GO-CFAR，区分真实生产路径与科学对照路径。历史数字仍是该阶段的结果，
不是当前阶段的验收门槛。

### 4.3 Current、传统两通道与四通道 STAP 基线

传统两通道 CSI 与四通道 STAP 曾因信息条件不同而被分开汇报。现在的纠正是：
二者应做端到端能力比较，同时保留信息量匹配层，避免把“增加空间自由度”误认为
“算法本身更好”。

### 4.4 通道时延注入与验证

通道时延是已有较清晰物理传播的误差机制。历史 M1/D3 结果表明，频率轴相位斜率
可以暴露时延，确定性校正可恢复部分相干性。这是“未知误差可由回波观测估计”的
证据之一，不是训练 AI 的自动理由。

### 4.5 慢时间相位漂移

慢时间相位漂移是另一类已实现、可测量的机制。历史 M2/P1 结果用于说明逐脉冲
相位模型和校正路径；它与固定相位、时延和几何误差不能混成一个无定义的 Oracle。

### 4.6 杂波时间去相干

历史 M3/`rho` 更接近杂波时间统计变化，而不是单一通道校准误差。相位对齐不能
自动恢复真实杂波创新过程；后续需把“系统误差可校准”和“杂波本身的时间去相干”
分开建模和评价。

### 4.7 D3/P1 证明部分未知误差可观测

D3/P1 的受控结果支持一个更窄、更可靠的命题：特定误差可在多通道回波中留下
结构化观测，并可用确定性估计器进行校正。还没有证明所有误差都可辨识，也没有
证明需要 AI。

### 4.8 J5/J6 联合校准

J5/J6 把多个机制和联合校准纳入审计。它们应被视为当前未知误差估计主线的历史
前置证据和候选组件，而不是必须由 Router 自动选择的最终系统。

### 4.9 目标迁移、Pd/Pfa 与目标保护

更相干的杂波并不自动意味着目标更安全。任何新校准都必须检查目标因果传递、目标
保留、Pd、Pfa 和虚警簇，而不能只报告 SCNR 或杂波抑制量。

### 4.10 Router 停止

Router Opportunity/Materiality 审计的结论 `NO_GO_AI_ROUTER_VALUE` 关闭的是
Current/J5/J6 路由这一支：其安全平均材料性不足。该结论不关闭未知 INS、伺服、
平台运动、通道同步和基线误差的观测与自校准研究。

### 4.11 下一阶段：真实系统未知误差联合估计

下一阶段先建立参数清单、传播图、观测量和可辨识性分析，再选择一个当前模拟器和
生产模型都能明确对接的首个 pilot。当前推荐从“基线几何误差的多波位观测”开始，
但必须披露现有注入器只对所选读入通道（默认通道 1/2）施加一阶相位扰动，因此它
不是完整四通道阵列几何误差的最终模型。
