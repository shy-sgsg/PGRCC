# 第一阶段后的 AI 方法建议

## 结论先行：后续 AI 最应该学什么，为什么？

最应该学习的是 **物理 CSI 参数的残差校正与置信度/门控**，优先顺序为：

1. 分数 CTDR 延迟或等效 P38 斜率的残差；
2. 每个 Doppler 行的复权幅度/相位残差，但必须带噪声放大抑制；
3. 由相干性、有效样本数和残余强点风险驱动的支撑/对消门控。

理由是本阶段的 Current–Oracle 数据同时说明了两件事：

- phase 单因素替换只带来约 0.06–0.07 dB 的 SCNR 变化，不像是当前最主要的
  瓶颈；
- 非理想条件下 delay 影响扩大，且幅度/复权 Oracle 能大幅改变残余高能点，
  但朴素 LS 复权会降低整体 SCNR。这意味着问题不是“缺一幅理想 clutter-free
  图”，而是物理模型在幅相误差、非均匀杂波和有效样本不足时需要知道自己
  什么时候可信、应校正多少、什么时候应保守旁路。

因此后续应采用 **物理模型保留 + 残差学习**，不要直接训练端到端
clutter-free RD 网络。

## 1. 建议的模型形态

先由现有程序生成物理初值：

\[
\theta_{phys}=\{k_{P38},b_{P38},\tau_{int},\alpha_m^{phys},
                 \mathcal S_{dyn},\gamma_{calib}\}.
\]

轻量残差模型只预测：

\[
\Delta\theta=\{\Delta k,\Delta b,\Delta\tau,
                \Delta\log|\alpha_m|,\Delta\angle\alpha_m,g_m\},
\]

其中 `g_m` 是 [0,1] 的行级可信度/门控，最终仍调用物理 CSI 算子：

\[
Y=\operatorname{CSI}\left(F_1,F_2;
  \theta_{phys}+\Delta\theta,g\right).
\]

优先推荐从一个很小的 MLP、1-D 行模型或浅层时序模型开始，而不是让网络直接
输出整个二维 RD 图。网络输入应来自物理处理中已经有的量：

- P38 拟合残差、RMSE、内点率和理论斜率差；
- 每个 Doppler 行的互相关幅度、相干性、两路能量比；
- 有效脉冲/样本数、丢失掩码统计和局部纹理非均匀度；
- 当前与 Oracle-like 物理估计之间的幅度比、相位散布和支撑边界距离；
- 当前对消后的局部残余功率、强点尾部统计。

这些输入可以让模型学习“物理模型偏了多少”和“这一行是否值得相信”，而不
需要学习距离轴、FFT、DBS、CFAR 和聚类的全部映射。

## 2. 训练目标的约束

Oracle weight 的训练/标定样本应继续遵守本阶段约束：权重或参数标签只从
clutter+noise truth、独立背景回放或硬件标定数据产生；不能通过目标 truth
优化 `alpha`。目标 truth 可以作为独立验证集上的目标保持/检测 guardrail，
但不应进入权重求解。

建议把损失拆成物理可解释的几部分：

\[
L=\lambda_1 L_{CN,residual}
 +\lambda_2 L_{tail}
 +\lambda_3 L_{noise\ floor}
 +\lambda_4 L_{smooth}
 +\lambda_5 L_{residual\ size}.
\]

- `L_CN,residual`：背景 C+N 对消后的平均/中位残余功率；
- `L_tail`：15 dB 强残余点、p95 或 top-tail 的惩罚；
- `L_noise floor`：防止通过放大/过拟合背景噪声换取局部低点；
- `L_smooth`：约束相邻 Doppler 行的参数残差平滑；
- `L_residual size`：抑制不必要的大幅度/大相位改动。

模型输出应与 Current 做受控混合，例如只在 `g_m` 高且有效样本足够时使用
残差权重；低置信度行继续走当前物理路径或旁路。这样可以直接针对本阶段
发现的矛盾：减少 high/FA，同时避免 LS 权重造成的 SCNR 下降。

## 3. 推荐开发顺序

### 3.1 先做无 AI 的物理基线扩展

先在更多 seed、纹理强度、幅相误差和丢失比例上补齐统计样本，并固定相同的
paired C+N/S+C+N 评价流程。至少要把以下三种对照分开：

- Current legacy 最小幅度对消；
- 物理 row-phase / fractional-delay，但保持保守幅度策略；
- 背景-only row-complex-LS Oracle。

本阶段只有每类一个单周期案例，足以做方向判断，不足以证明泛化。

### 3.2 第一版 AI 只学习一个残差头

优先实现 `Δτ` 和 `Δlog|alpha|`/`g_m` 的小模型，保留 P38、四通道融合、
距离向校正、动态支撑、CSI 算子和 CFAR。phase 残差可作为第二个输出，但
当前结果不支持把 phase 作为唯一主攻方向。

每次实验都输出同一套指标：`CA/CSR`、输入/输出 SCNR、SCNR 提升、
`target_loss_dB`、`residual_high_energy_points`、`false_alarm_count` 和 `Pd`。
模型只有在背景残余、尾部强点和虚警改善的同时不破坏目标保持时才进入下一轮。

### 3.3 数据划分

训练/验证/测试应按场景和随机 seed 划分，不能把同一场景的不同脉冲简单随机
拆分后当作独立样本。非理想数据需要保留真实的有效样本掩码，并覆盖从高到低
的有效比例、非均匀纹理等级、固定幅相误差和脉冲相位抖动组合。

## 4. 明确不建议的路线

不建议下一步直接训练 `raw IQ → clutter-free RD` 或 `RD → cleaned RD` 的
端到端网络，原因是：

- 它会把已验证的四通道融合、CTDR 延迟、P38 物理斜率、支撑边界和 CFAR
  统计一起隐藏，难以判断性能提升来自哪里；
- 本阶段已看到“残余高能点下降”和“整体 SCNR 下降”可以同时发生，单一图像
  损失容易奖励噪声放大或目标削弱；
- 有效样本不足时，端到端网络可能把丢失模式当作场景捷径，跨设备和跨纹理
  泛化风险更高；
- 目标 truth 禁止参与 Oracle 权重求解的约束，在黑盒端到端训练中很难审计。

结论是：下一阶段若获准进入 AI，应把网络限制在 **物理参数残差、可信度和
门控** 这三个接口，物理 CSI 主链和检测链保持可追溯、可旁路、可单因素复现。
