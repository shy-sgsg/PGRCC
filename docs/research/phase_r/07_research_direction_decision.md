# Phase R 研究方向决策

日期：2026-10-22。证据截至 R3/R4 当前归档，不包含新实验。本报告回答原始研究任务 Q1–Q12；相关证据入口为[架构审计](01_system_architecture_audit.md)、[文献综述](02_literature_review.md)、[物理边界](03_physical_limits.md)、[评价链路审计](04_evaluation_pipeline_audit.md)、[冻结实验设计](05_experiment_design.md)和[合并结果](06_bottleneck_experiment_results.md)。旧的[初步方向评估](07_preliminary_direction_assessment.md)保留为 R3/R4 当时的阶段记录，不以新报告覆盖。

## 决策摘要

- **AI 必要性：尚未建立。** 这不等于 AI 已被证明无价值。当前没有把盲确定性估计的残差证明为跨独立 seed、跨误差/场景稳定且可由额外可观测信息改善；不训练网络、不启动 Router、不做 image-to-image 或六参数联合估计。
- **候选方向的本地证据排序：不能再概括为 C > A > B。** C（未知物理时延误差）仍有唯一修复后、有效地杂波条件下的三 seed A/B/C 任务级因果方向证据。R4 的 **target-free H0 false-CUT fraction** 为 `2.9937%` / `3.2415%`，使 CFAR/相关杂波成为优先审查的测量风险；但只有一个 seed/三个相关 period，且八个摘要行重复相同 hit-hash 签名，不能据此确认普遍 Pfa 失配或非均匀杂波根因。A（低速/目标保护）仍因低速背景 ROI 缺失而不可排序。这里的优先级是“先修复/验证哪些测量门”，不是论文主线胜者排序。
- **总体研究主线状态：`INCONCLUSIVE`。** R3 只改变一个通道时延、一个目标场景；R4 只有 seed 101，且低速 P5 背景 ROI 与跨 branch 唯一 hit union 未闭合。R4 的通用 residual-closure evaluator 原始输出虽为 `NOT_EVALUABLE`，但零时延 E1/E4/E5 的物理校正残差闭合为 `NOT_APPLICABLE`，不构成该 pilot 的失败门。没有真实机载原始数据证明仿真误差的代表性。
- **近期优先事项：先修复/冻结 E1/E4/E5 评价契约并只重审 seed 101；未过门不扩 seed。** 若评价门通过，再以独立 seed 扩展预注册的零时延条件；盲估计器 D3 的独立 seed 复验是另一项有条件候选，不自动启动。

## Q1–Q12 回答

### Q1：GMTI 的基础限制有哪些，不同体制是否相同？

**证据/判断：** 基础限制包括有限空间/时间自由度、目标与杂波空时谱重叠、有限且可能非均匀的训练数据、通道/平台运动补偿失配、多普勒模糊与参数耦合、杂波抑制造成的信息损失，以及相关 CUT 下的门限/虚警校准。这些机制普遍存在，但严重程度不相同：PRF、波束、阵列基线/通道数、脉冲数、平台运动、处理域和杂波环境共同决定边界。

**PGRCC 对应：** 四路协议 IQ 先融合为 F1/F2，生产 CSI 只用两路复数输入形成一个差分输出；因此不能直接套用高维 STAP 的独立空间自由度/协方差样本要求。当前 CSI、几何投影和 Doppler ambiguity 的界限见 [03](03_physical_limits.md)。

**未知：** 现有仿真是否覆盖真实 airborne clutter、硬件误差分布和任务 operating envelope；当前没有足以给出普适瓶颈排序的真实机载样本。

### Q2：未知系统失配是否重要，在当前 PGRCC 贡献多大？

**直接证据：** R3 的单通道 `+4 ns` 条件 B 相对 A，在 seed 101/202/303 的角度、跟踪地速、位置 RMSE 全部恶化；三 seed 中位误差约增至 `2.85× / 1.76× / 2.40×`。H0 CSI cancellation 中位数下降约 `0.459 dB`。Known correction C 将三 seed 中位 RMSE 相对 B 降低约 `89.5% / 86.0% / 89.6%`，并与 A 完成 `1e−3` F1/F2 复数闭合。

**解释/限制：** 这是一个仿真误差参数、一个目标场景、3 个 seed 的证据；paired-t 95% 区间在三项任务 RMSE 上均跨 0。H1 hit 数为 3/3，未观察到漏检差异；adaptive Output SCNR proxy 反而在 B 更高。故可说“该设定下任务 RMSE 有同向退化及已知校正恢复”，不能说未知系统失配是主要/普遍瓶颈，也不能给出真实系统总体损失份额。

### Q3：完全理想校准后，低速目标检测仍受限吗？

**直接证据：** R4 零通道误差下覆盖配置地速 `0.5–4 m/s`，逐期 truth 的径向速度均值约 `0.489–3.909 m/s`；40 个 ON branch 的 120 个可见 period 目标机会均记为检测命中。

**解释/未知：** 这没有证明低速性能不受限：只有一个 seed、每 branch 三期；TrackManager `track_pd_all_visible` 为 `2/3`；0.5/1 m/s 的 P5 背景 ROI 为 `0/30`，2 m/s 为 `20/30`。需先修正/冻结 ROI 与检测关联评价，再决定是否存在低速损失。也没有构建 Pd–相对径向速度曲线。

### Q4：F1/F2 结构是否造成不可忽视的目标信息损失？

**物理/代码事实：** 物理四路 IQ 融合为 F1/F2 后只剩两个 CSI 输入；现有按 Doppler 行估相位、最小幅度均衡再相减。理想化推导中，目标相对杂波参考相位接近时响应可趋近于零，说明目标自对消在该结构中可能发生；它不是实测损失率。

**本地证据：** R3 A 与 C 的 ON/OFF/TO 目标传递代理闭合；R4 4 m/s 可评估的 `target_loss` 为小幅负值（表示目标功率轻微增加），而不是目标损失。R4 更低速 ROI 缺失，不能外推。

**结论：** 双通道信息上限客观存在，但当前尚无证据量化其在完整速度/方位范围内造成“不可忽视”的任务损失；也没有同输入四通道 STAP 的可比结果。

### Q5：传统杂波对消的不足来自哪里？

**直接证据：** 当前 CSI 是双通道 row-wise 相位参考/幅度均衡/差分，不是高维样本协方差逆；R3 的 `+4 ns` 会改变通道跨频相位并降低 B 的 H0 cancellation，Known physical inverse 可恢复闭合。R4 C0–C3 零误差结果中，低速背景 ROI 缺失；4 m/s P5 的各方法 SCNR change 与 CA_ROI 均为负。通用残余闭合 evaluator 因缺 PK/PKR 输出 `NOT_EVALUABLE`，但零时延物理 residual closure 对该 pilot 为 `NOT_APPLICABLE`。

**结论/未知：** R4 target-free H0 的两个 CFAR 分支分别观察到 `47,356/1,581,840=2.9937%` 和 `51,275/1,581,840=3.2415%` CUT 超阈；因 H0 无目标，可作为该场景的分支级 false-CUT fraction。它高于 configured Pfa `1e−6`，但不是经相关性/独立 seed 校准的 empirical Pfa；分支 hash 只有摘要，跨 detector branch 的唯一 cell union 仍未知。该现象使门限/背景统计匹配成为真实候选问题，但不能单独归因于空间非均匀性，也不能据此估计一般 false-alarm 性能。E3 修复前历史结果仍不具备当前生产归因资格。须在明确目标保护、H0 身份、背景支持和分母口径的受控单因素对照下继续判别。

### Q6：杂波抑制比越高，检测一定越好？是否损害参数估计？

**答案：** 不必然。R3 B 的 adaptive Output SCNR proxy 中位数高于 A（约 `+2.19 dB`），但 B 的角度、地速、位置 RMSE 都更差；R4 4 m/s 下各方法 SCNR change/CA_ROI 为负，而 target_loss 为负（小幅目标功率增益）。这是不同指标可冲突的直接例子，不足以确定哪一方法更好。参数估计只能在正确关联目标上条件评价，并另列全体目标机会命中数。

### Q7：传统方法还有多少可恢复空间，哪些强基线缺失？

**已量化部分：** 在 R3 这一 `+4 ns` 设定，Known correction 相对 B 的三项 RMSE 中位降幅约 86%–90%，CSI cancellation 从 B 回到 A 附近；seed 101 的 D3 blind 仍比 C 高约 `2.57×–4.11×`，但只有一个 seed。R4 的 target-free H0 分支 false-CUT fraction 可描述性计算，但 pooled/跨分支检测虚警与 statistically calibrated Pfa 仍不可评估。

**缺口：** R4 的低速背景 ROI、跨分支 hit-cell union/检测级虚警及统计校准 Pfa 尚未闭合；零时延物理残余闭合不适用。Mode-B 仅源码/测试核验，没有 Production 运行；C4/scan 完整门未在本轮复验。目标保护、low-speed 对照和径向速度误差尚未闭合。Known correction 是 evaluator-only 上限，不是可部署基线。

### Q8：近年研究解决了什么，哪些已不新颖，仍有什么空间？

**文献证据：** [literature matrix L14–L19](literature_matrix.csv) 覆盖近年四通道残余相位低速检测、地形辅助 DTD-3D-STAP、有限样本 MNEC、三通道 airborne flight-test 摘要、非 GMTI SAR 高阶统计校准，以及仿真/模型驱动 DU-ANM-STAP。它们证明相关路线仍活跃，不证明问题已被普遍解决；数据与 PGRCC 的通道自由度、处理域、实测等级各不相同。L16/L17/L19 仅摘要证据，L18 的应用体制并非 GMTI。

**创新边界：** “使用 AI”“做 STAP”“联合校准与杂波对消”本身都不能作为创新。可能的窄空间是从 target-free F1/F2 估计真实物理时延并给出不确定度，接入当前双通道 CSI，验证从校准残差到检测/参数的因果闭环；需要先完成传统估计和可观测性对照，且与近期文献的差异仍待逐篇审查。

### Q9：为什么需要 AI？不用 AI 能做到什么？

**结论：** 当前没有理由说“需要 AI”。Known physical correction 已能按已知参数逆校正，seed 101 的 D3 target-free Huber 加权 LS 已估出有限时延；但单 seed 残差并不能证明确定性方法的稳定上限。下一步应先多 seed 复验 D3、报告有效支持/估计偏差/残差/不确定度及端到端任务指标。

只有当真值不泄漏、可观测性已确认、确定性估计在独立 seed/场景上留下可重复且有任务代价的残差，并且有具体可用的观测特征可突破该残差时，才进入小型 Physics-AI 设计。输出应是有单位的物理参数、残差和置信度，并与同信息条件最强确定性方法比较；否则保持 `ai_training=false`。

### Q10：下一篇论文应选哪条主线？

**当前不做最终选定，状态 `INCONCLUSIVE`；C 是下一步优先验证方向。** 候选论文问题可暂表述为：“在两路融合后的 airborne GMTI CSI 链中，target-free 多通道观测能否稳定识别真实通道时延，并把可恢复的校准收益传递到检测与参数估计？”

- **物理假设：** 通道时延引入与频率成比例的相位斜率；在有效输入带宽和 F1/F2 相干性允许时，可由目标自由杂波观测估计，再应用匹配物理逆算子。
- **实验基础：** R3 三 seed 的 B/A 任务 RMSE方向和 C/B 恢复方向，且 A/C 输入闭合通过；D3 seed101 给出有限盲估计残差。
- **可能贡献：** 建立观测可辨识性、target-free 物理时延估计/不确定度和生产端任务级因果收益之间的可审查闭环，而非单纯降低 CSI 残差。
- **主要风险：** 单误差/单场景不代表真实设备；R3 任务 CI 跨 0；D 仅一个 seed；两路观测下多个 nuisance 参数可能混淆；Pfa、径向速度和真实 airborne 外部验证缺失；近年校准/学习文献较多。
- **反对证据：** B 的 Output SCNR proxy 较高且 H1 hit 不变；R4 零误差低速 P5 未闭合，且 H0 false-CUT fraction 很高但只有单一相关 H0 realization，提示应先核实 CFAR/背景模型而非直接确认 B；A/B 仍可能是更主要瓶颈；确定性估计可能已足够。
- **可否证条件：** 修复所有评价门后，若 B 相对 A 的关键任务误差不再同向恶化，或 C 相对 B 不呈重复改善/已知校正不能闭合，则暂停 C 主线；若盲 D3 跨独立 seed 接近 C 且残差不产生任务损失，则不进入 AI；若低速/杂波控制实验显示更稳定的任务损失，则重排为 A 或 B。

### Q11：下一步先复现哪一种方法？

**先完成测量门，而不是新增算法。** 测量门通过后，最有判别力的算法复现是 D3_Huber_weighted_LS target-free blind physical delay estimator：在不读取 truth、A0 配对参考或 ON 的前提下，使用独立 seed 的 A1_OFF 融合 F1/F2 估计时延；记录有效频点/支持、估计偏差、拟合残差、置信区间，并只把估计值用于 Production 校正。它直接检验 C 方向与 AI 入口的关键缺口，且比立即训练网络更容易审计。

运行前必须只读确认 seed 202/303 的估计输入时序数据是否仍在本地。若只有摘要/哈希而没有所需复数样本，不得假称可重用；需另行批准一个仅生成 target-free 估计输入并保留小型输入摘要的新运行。不得重跑 A/B/C 全矩阵。

### Q12：下一阶段任务如何安排？
