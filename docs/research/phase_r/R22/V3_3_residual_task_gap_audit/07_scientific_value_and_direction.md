# 07｜科研价值与方向判断

## 对总体 GMTI 目标的贡献

本阶段只对 V3.2 已完成的筛选归档做离线任务残差审计。它把“固定 +4 ns 会造成检测退化”和“确定性估计能否恢复不同任务量”分开检查，并揭示目前归档对完整参数共同成功评价的周期覆盖不足。这推进了研究总纲要求的物理条件、强传统方法、可评价性和任务指标闭环，但仍是筛选证据，不是确认性性能验证。

## 可支持的结论

1. 在当前固定仿真误差、连续面积杂波和冻结评价口径下，+4 ns 的 Current 检测命中率明显低于 A0；Known correction 的检测命中率与 A0 汇总相同。该结果跨 12 个 seed 的筛选一致，但不是跨真实平台误差分布的结论。
2. target-present Huber D3 ON 与 M1 的检测命中率接近 Known，显示确定性估计路径在本筛选中已有很强的检测恢复表现。不能因为估计残差不为零就宣称检测性能仍存在显著缺口。
3. 参数误差不完全闭合：period 8 共同成功子集的方位和位置误差仍落后 Known；完整十周期共同机会与地速共同成功不可评价。因此后续应优先补齐输出和共同机会，再判断该残差是否稳定、重要且可恢复。
4. A0 与 PK 在命中总数和归档 own-success 参数摘要上近似闭合，但并非逐机会完全相同。
5. 本任务没有测试复杂非平稳杂波，也不构成低速目标保护的专项对照。现有结果不足以将这两者提升为优先研究主线。

## 方向裁决

- **长期主题：** `CONTINUE` 研究总纲规定的物理模型驱动 GMTI 稳健杂波抑制、检测与参数估计；本阶段不提出总纲变更。
- **局部优先级：** 若用户批准继续，先冻结一份输出完整的确认性实验契约，检验 target-present 确定性估计的参数残差与轨迹/目标保持，不立即开发新算法。
- **AI 进入门：** `FAIL`。target-present 确定性 Huber/M1 在检测命中上已接近 Known；尚未证明传统估计器留下稳定、独立场景可复现且无法由确定性改进解决的任务残差。
- **低速/复杂杂波：** `NOT_VERIFIED_AS_PRIORITY`。V3.2 的速度分层筛选并非低速保持专项确认，复杂非平稳杂波也未测试。
- **不得外推：** 本轮不报告统计显著的 Pd/Pfa 改善，不宣称真实机载泛化，也不把 false-confirmed track 或 false-CUT 当作系统 Pfa。
