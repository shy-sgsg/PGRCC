## 2. 已实现内容

1. **周期因果估计：** M1 与 Huber D3 使用相同的 ON C1/C2 观测前缀 `0…k`、频率支持/几何与校正边界；估计在周期 `k` 输入结束后完成，并只用于当前周期。无效估计采用该周期显式零校正，不沿用旧值、不跨方法 fallback。估计路径记录各周期的前缀输入身份与运行状态。
2. **目标复数响应：** 新增 `r22_v4_evidence.py`，以注册的 `CSI_AFTER` tap 保存每个目标、周期、方法、角色共用的固定 truth-centered 5×5 ROI 逐格复数值、功率、ROI 重叠和输入/源码身份。TO-only 信号路径提供目标响应观测；不同角色自适应处理结果只作为诊断，不假设 ON/OFF/TO 线性闭合。
3. **归档与续跑：** 新增 V4 专用归档 profile，保留 Production 分支、全周期 Detection、TrackManager/PIPE、运行 manifest、目标响应和必要审计资料。续跑前核对 ZIP SHA、归档 manifest SHA、profile、成员清单、V4 必需成员及 ZIP CRC；不匹配时 fail closed。清理 raw `.bin` 和稠密数组前，先验证目标响应文件及其身份。
4. **设备身份：** V4 运行 manifest 记录 CUDA 可用状态和驱动版本；V4 完整归档要求该身份存在。此字段只表示运行环境身份，不证明输出正确或性能合格。

目标中心目前由 `A0_ON` 的逐周期真值确定，另将其来源路径、大小与 SHA 写入输出 manifest。**尚未在真实 V4 输入上独立核对 `A0_ON` 与 target-only/受误差场景真值的逐目标、逐周期映射**；这项身份核对保留为独立审查及授权 pilot 的门，不得仅凭合成测试宣称已闭合。
