# R11 研究方向裁决：确定性时延标定是否影响 GMTI 测角定位

## 决策摘要

**本场景内已得到受控证据：固定通道 2 时延校正残差会显著改变 Production 的 CTDR raw phase 和固定 cell 测角/定位。** 将 3.409965 ns 校正提高到注入已知值 4 ns，使 ch2/F2 输入残差由 `0.05311/0.06327` 降为 `7.62e-5/9.08e-5`，固定 cell 相位差由 `0.0177709 rad` 降到 `4.47e-8 rad`，fixed-cell 二维误差由 `45.640 m` 回到 A0 的 `10.757 m`。这支持继续研究更准确的传统物理时延标定；证据仅限一个 seed、一个 period、一个固定目标。

**任务级端到端收益尚未被这组扫描确认为单调。** 冻结 evaluator 前五点匹配 `(129,2155)`，4 ns 改匹配 `(48,2154)`。固定 cell 的闭合是强机制证据，但不同候选间的任务指标不能拼接成同一目标的平滑性能曲线。Known correction 恢复到 A0，并没有消除 A0 约 10.76 m 的基线定位误差。

## Q1–Q8

1. **Q1：F2 是否随校正量接近 4 ns 而接近 A0？是。** 相对 RMS 从 `0.102452` 单调降至 `9.0822e-5`，ch2 从 `0.0860025` 降至 `7.6240e-5`；F1 全程为 0。4 ns corrected IQ 与 R8 Known 输入 hash 一致。
2. **Q2：目标 CTDR 相位是否同步接近 A0？是。** 固定 cell 的 raw phase 差由 `+0.0289193` 降至 `−4.47e-8 rad`；CSI target-cell 复响应也逐点靠近 A0。4 ns 物理已知值闭合门通过。
3. **Q3：相位变化能否预测测角与位置变化？在注册 fixed cell 的局部邻域内可以。** 使用 A0 固定 Jacobian 对 cross-range 变化预测，六点最大残差 `0.01449 m`。这是生产映射闭合证据，不足以单独证明全部真实误差都来自时延。
4. **Q4：误差是否随残余时延缩小而降低？固定 cell 诊断是，冻结 matcher 的任务候选序列不是同一候选。** fixed-cell angle/2D error 连续下降；matched detection 的前五点误差下降，但在 4 ns 候选切换后误差回到 A0 水平。不能作无条件任务收益声明。
5. **Q5：相位残差很小时，定位误差是否仍明显？是。** 4 ns 与 A0 的相位/几何闭合已达到数值精度，但绝对二维误差仍约 `10.757 m`，与 A0 相同。这是本链路基线误差，不应归因于已被闭合的时延残差。
6. **Q6：分数延迟插值、融合与 CTDR 各自贡献了多少？本实验没有独立分离。** 4 ns corrected float32 IQ 与 A0 的实测 ch2/F2 closure 分别为 `7.62e-5` 和 `9.08e-5`；本实验没有将该微小残差分解到逆算子插值、float32 舍入或输入差异。物理通道 2 变化经 `(2,4)→F2` 后改变 CSI 与 CTDR raw phase；production Jacobian 再把固定 cell 相位变化映射为横向位置变化。没有插值核替换、融合消融或独立 CTDR 算法对照，因此不能给各算子分配百分比。
7. **Q7：是否支持继续做更准确的物理通道 2 确定性标定？支持作为下一阶段候选。** 固定 D3 残差在受控输入中可追踪，Known correction 可闭合输入、CSI、相位和 fixed-cell 几何。下一阶段应先冻结目标匹配与误差口径，并验证一个真正由观测产生的确定性估计值能否恢复这条链；R11 的 4 ns 是 Known-correction upper-bound 条件，不是可部署估计器。
8. **Q8：是否有证据证明需要 AI？没有。** 本实验使用确定性物理校正量扫描，尚未证明合格的传统估计器存在性能上限，也没有估计残差、置信度或跨 seed 的盲估计证据。禁止据此训练 AI。

## 状态与停止决定

| 状态 | 判定 | 依据 |
|---|---|---|
| `IMPLEMENTED` | 是 | 冻结设计、输入校正、Native CUDA runner 与评价代码已完成 |
| `EXECUTED` | 是 | RTX 3050 Laptop GPU 上六个正式 Production 分支完成；另保留一次入口失败 |
| `EVALUABLE` | 是，限定于报告指标 | 输入 closure、fixed-cell CSI/phase/geometry、冻结 matcher 输出和候选 lineage 齐全 |
| `PERFORMANCE_VERIFIED` | 仅 fixed-cell 条件响应；任务级泛化否 | 单 seed/period；truth 候选在最后一点切换；无 Pd/Pfa 统计 |

不自动进入 R12、不扩 seed、不开始 AI 训练。推荐的下一步方向是**物理模型匹配的确定性通道时延标定与目标候选稳定性审计**；在任何后续实现前，先明确估计器只读哪些观测、如何避免 truth/配对 A0 泄漏，并将候选匹配代价与任务误差分开报告。

## 最终科学问题

**是否已经找到传统确定性标定尚未充分解决、并会实际影响 GMTI 测角定位精度的问题？**

答案是：**在当前注册场景的固定 Production cell 上，是；作为跨场景的任务级性能结论，尚未完全确认。** R11 给出了受控的延迟—融合输入—CSI—CTDR phase—几何响应链，并与 4 ns 已知校正及 A0 参考闭合。但它没有评估一个盲估计器，也没有解决候选切换和 A0 的绝对定位残差。下一步应检验确定性观测估计器与候选选择口径，之后再判断物理状态可观测性的剩余缺口。没有 AI 必要性证据。
