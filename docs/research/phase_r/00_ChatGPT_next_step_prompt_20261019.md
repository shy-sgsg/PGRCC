- AI Router/专家选择相对安全确定性策略的价值；

它们不能互相替代。当前生产主链是四路协议 IQ 经 `(1,3)/(2,4)` 融合为 F1/F2，再进入双通道 CSI、CFAR、检测和 TrackManager/PIPE；四个物理通道不等于四个独立自适应空间自由度。

## 必须重点独立复核：Phase-I 圆周相位敏感度

现有审查材料曾报告 54 个 Phase-I case、13×6 局部敏感度矩阵 rank=6、条件数约 37.33，以及 channel delay 与 servo angle 灵敏度列余弦约 −0.920。不要直接沿用这些数值作为可靠结论。

一项尚未并入正式报告的本地复核发现：观测量 `cross_channel_phase_rad` 是圆周相位，而旧的中心差分似乎直接对正负扰动的相位角作普通减法。若正负样本跨越 ±π，差分会引入约 2π 跳变。对已保存的 54 份派生观测做圆周差分后，汇总矩阵仍为 rank 6，但条件数约 3.99，delay-servo 列余弦约 −0.068；三个 seed 单独计算的条件数约为 69.75、10.11、3.40，参数混淆关系也随 seed 改变。这些数字是待核验的复算结果，不是新的原始 IQ 实验，也不证明实际估计精度或可恢复性能。

还需检查 `clutter_doppler_ridge_hz` 是否为量化 FFT argmax 特征，而非平滑局部观测；一个 seed 的平台速度响应似乎包含单个频率 bin 跳变，纳入该特征会显著改变速度列灵敏度。请将离散/跳变特征与连续局部敏感度分开，按 seed 展示结果，并说明尺度归一化和汇总方式对条件数、列相关度的影响。

如果仓库快照没有保存这 54 个 JSON 观测或生成差分矩阵的源码，请明确标注“无法从 GitHub 包独立复算”，不要假装已验证上述复算值；指出复核所需的最小文件/命令。即使复算成立，也只能更新局部可观测性判读，不能推出噪声下估计可行、全局可辨识、生产性能损失或 AI 优势。原始 IQ 已不在可审材料中，因此也不能据此验证 IQ 到观测量的提取链。

## 评价规则

- 区分直接证据、推断、建议和未知项；关键断言尽量给出仓库文件路径、行号或具体产物字段。
- 区分理论/代码审计、软件测试、历史仿真、真实 CUDA production 执行和端到端性能验证。`completed_with_gaps`、测试通过、文件存在或配置 Pfa 均不等同于算法有效、实测 Pfa 或 Pd 结论。
- 四条件适用时，区分 Ideal/No-error、Current+unknown-error、Known-error correction upper bound、Estimated-error correction；明确指标方向与信息条件。
- Known-error correction 只能是 evaluator-only 上限，不能泄漏给盲估计器。比较目标保持、杂波残余、检测/虚警、定位/航迹时，使用可比输入和明确分母。
- Physics-AI 的进入门槛至少应讨论：未知误差造成可重复的生产链损失；已知误差校正显示存在可恢复空间；盲确定性方法在公平条件下恢复后仍有稳定、可归因的残差；AI 能利用确定性方法未利用的信息且不破坏目标、虚警和航迹安全。门槛未满足时不要建议训练 MLP、通用复权残差、image-to-image 或 Router。
- 不臆造收益阈值；建议如需实验，先给出可判别假设、最小对照、观测量、统计单位、失败/停止条件。不要在此提示词任务中启动实验或改代码。
