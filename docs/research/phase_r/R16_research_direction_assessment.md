# R16 研究方向评估

日期：2026-10-25。依据：[R16 结果报告](R16_minimal_c1_results.md)、[冻结实验设计](R16_experiment_design.md)及[紧凑证据包](evidence/r16_c1_gamma1_seed505/README.md)。

## 判断

**阶段裁决：R16 C1 pilot `STOP`；总体传统基线研究 `CONTINUE`，但只保留有限、由用户启动的可比性补证方向。`PIVOT` 不成立。** C1 固定 Gamma=1 在本次 seed505 正常速度、零时延场景表现不足；该结果不支持继续调 Gamma，也不足以排序 C2/C3，更不能据此改变长期研究方向。R16 是一个传统方法边界测量，不是未知通道误差因果实验。

## 证据与解释

同一次 Native CUDA 执行中，C1 与 C0 使用相同 Stage2 输入及 F1/F2，分支参数门审计闭合。C1 的目标检测为 ON 1/3、TO 1/3，而 C0 均为 3/3；C1 的 H0 cancellation、TO target-only CSI retention 和 evaluator SCNR proxy 也更差。C1 非目标检测行更少，但 empirical Pfa 不可评估，因此不能将其解释为虚警改善。

R14 的 C2/C3 表现不能直接作为 C1 的跨阶段对照：Stage2 输入确实逐文件匹配，但 Production executable 不同，且下游 C0 CFAR maps 9/9 不同。故不能用这些 R14 结果判断 C1 相对 C2/C3 的净收益。本次也不重跑方法矩阵。

信息量上，C0 与 C1 都不需要额外 paired OFF；R14 的 C2/C3 Mode-A 使用 paired OFF fitted reference，OFF/H0 属于 reference-in-sample。因而任何未来性能差异都需区分算法收益与额外信息收益。R16 没有验证可部署 secondary-data 的来源或其估计性能；不能断言实机可获得合格 background reference，也不能断言不存在更好的确定性方法。

当前传统 Baseline 矩阵新增了同次执行、同输入、无额外 OFF 信息条件下的 C0/C1 对照，但没有建立跨 C0/C1/C2/C3 的有效统一排名。C1 的固定单位复权相减无法补偿未知的幅相差异，结果与这种极简方法能力不足相容；本实验未隔离出该机制为漏检的唯一原因。哪些任务瓶颈优先级最高仍未由 R16 识别。

## 对长期问题的回答

1. **未知通道误差是否确实降低 GMTI 性能？** R16 注入时延为 0 ns，不能回答。R16 不改变未知系统误差的证据状态。
2. **已知物理校正能够恢复多少？** 本次没有通道失配，不存在此处可估计的 recoverable space。
3. **传统盲估计与已知校正相差多少？** 本次没有执行盲估计或已知校正条件；无可报告差值。
4. **是否应继续研究未知物理状态估计？** R16 既不建立也不否定它。AI 必要性仍未建立；C1 失败不等于盲估计失败。
5. **是否转向低速目标保护或复杂杂波？** 不应依据本次正常速度、零时延单场景作此转向。R16 没有比较低速或不同杂波模型。

6. **传统 Baseline 矩阵补齐了什么？** 补上 C1 Gamma=1 的真实 Production 边界，并给出与 C0 同信息条件下的配对结果；没有补齐公平的 C2/C3 同 binary 排名。
7. **下一阶段先研究什么？** 现有证据不足以在杂波统计估计、目标保持和其他任务瓶颈之间做科学排序。若用户启动下一阶段，先核验可部署 secondary data/reference 的真实来源，并统一 Production executable 与评价门；再决定是否做有限确定性方法对照。此为待用户启动的建议，不是实验授权。
8. **研究主题与整体技术路线是否改变？** 不改变。R16 没有新的未知系统误差因果证据。
9. **AI 是否有真实必要性证据？** 没有。固定 C1 失败不能推出 paired OFF 必需，更不能推出 AI 必需。

## 下一步建议与停止条件

当前阶段已经停止；没有自动授权的新实验。若用户后续指定研究工作，先解决跨运行 Production executable 身份与方法对照可比性，再判断是否需要一个严格同 binary 的有限传统方法复核。任何新任务仍需重新审查总体科学价值与可评估指标。若无法建立相同处理链或真实任务分母，则停止方法排序，不以更多单 seed 运行掩盖该限制。此建议不构成 AI 训练、扩大 Baseline 矩阵或研究方向 pivot 的授权。
