# R12 盲时延估计验证

日期：2026-10-24。独立验证数据：seed 404，单一 C2 `+4 ns`，390 pulses，Native CUDA Production。

## 盲估计隔离

M1 输入仅为 B 条件 `A1_Current_unknown_error/ON` 的原始协议 C1/C2、逐脉冲头字段波束角，以及 B 条件 Production XML 中的报告几何。估计器没有读取注入误差、A0/Known 配对 IQ、目标真值、检测或校正后的数据；真值只在估计结束后由 evaluator 计算误差。输入文件 SHA、运行 XML SHA、估计源码身份均记录在[紧凑证据包](evidence/r12_physics_matched_delay_20261024/)的 `pilot_summary.json`、`artifact_index.json` 和原始 manifest 中。

M1 按 Stage2 同一零扩展线性分数延迟响应拟合一个常数复增益。390 个脉冲形成 2,364 个支撑频点，跨度 21.812 MHz；估计为 **3.759357 ns**，相对 4 ns 的 evaluator-only 误差为 **−0.240643 ns**，归一化复谱残差 0.045710，phase RMSE 0.042877 rad。M1 输入、支撑门、搜索界和拒绝规则见[物理匹配估计器说明](R12_physics_matched_estimator.md)。

## 校正后物理闭合与任务表现

M1 估计只驱动 C2 的 Stage2 逆递推校正。与配对 A0 的 F2 输入相比，M1 的相对 RMS 残差为 2.6840%；固定 R9 D3 为 6.3719%；Known physical correction 为 0.00873%。因此 M1/D3 都未达到 Known 的输入级闭合。其任务结果为 M1、固定 D3 各有 3/3 正确检测机会，2/3 正确 TrackManager 关联；A0/Known 为 2/3、1/3；B 为 0/3、0/3。M1 相对固定 D3 的角度和位置 RMSE 较低，但地速 RMSE 较高，指标方向不一致。

每个条件仅三个目标机会。配对 H0 OFF 的 false detection 行数 / false confirmed track 数分别为：A0 27/3、B 33/6、Known 27/3、固定 D3 28/2、M1 27/2。它们是单次描述计数，不构成 Pfa。CFAR 唯一 union hit 数值审计与径向速度 RMSE 均为 `NOT_EVALUABLE`。

## 已知失败边界

- 合成几何扰动中，未建模的逐脉冲几何相位可将 4 ns 偏置到 4.468978 ns，而归一化拟合残差仍仅 0.005373。低残差不能证明几何模型正确。
- 如果通道间相对频响可在带内任意变化，时延与未知频响不可辨识；M1 的单一复增益假设必须由外部标定支持，超出时应拒绝估计。
- seed404 中 M1 虽恢复全部三个检测机会，输入 F2 仍与 A0 有 2.684% 相对 RMS 差异，且地速 RMSE 为 11.03 m/s，高于固定 D3 的 8.06 m/s。检测计数不能替代参数精度或闭合门。

## M1 残差归因状态

- **数学可辨识性：** 在已声明的常数复增益模型和可信几何内，seed404 有可用频率支撑并得到内部解；若允许任意未知频变复响应，则数学上不可辨识，不能靠更多优化迭代修复。
- **数据支持：** 本次支撑为 2,364 bins、跨度 21.812 MHz，超过冻结门 8 bins/3 MHz；M1 返回 `ok`，不是因支撑门不足而拒绝。杂波/噪声仍可能影响估计，但当前单 seed 不能量化其贡献。
- **数值优化：** 401 点粗扫后在最佳相邻区间执行有界 golden-section；解没有触及 ±0.49 sample 边界，合成正负时延回归通过。本次没有数值失败证据。
- **观测模型：** 估计仍低于 4 ns，模型残差门虽通过，合成的逐脉冲几何扰动也证明低残差可以伴随明显偏差。因此几何误差或未建模的频变响应是合理的待查来源，但当前 seed404 证据不能在两者之间定因。不能把未定因的残差解释为需要 AI。

## 判定

**M1 已实现并在独立 seed404 上完成一次盲估计与 CUDA Production 任务验证；性能仍未验证。** 本阶段作为固定时延支线的最后一次优先验证，M1 保留为确定性 Baseline；不继续将其作为主创新方向，也不自动扩展 seed。最终决策为 `PIVOT`：转向其他 GMTI 性能瓶颈的公平 Baseline 评价，不支持推广到未知宽带频响、任意变化几何或 AI 模型，也不支持统计性 Pd/Pfa 声明。
