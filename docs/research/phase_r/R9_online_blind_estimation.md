# R9 ON 数据确定性盲估计

## 估计协议

在线候选只读取每个留出 seed 的 `A1_Current_unknown_error/ON` 三期四通道协议 IQ，计算四通道生产融合 F1/F2 后执行 D1/D2/D3。估计函数只接收 IQ 与布局参数；没有传入注入时延、A0、OFF、TO、目标 truth、检测结果或配对参考。使用完整三周期 H1 数据，允许目标存在；不依赖 target-free 规则或额外 oracle。选择规则在 Production 前冻结为第一个有限值 `D3 → D2 → D1`，两个 seed 都选中 D3。

这是一种“目标存在的 ON 数据批量盲估计候选”，不是在线部署证明：估计是在同一三周期数据收齐后完成，再把参数用于回放同一批 ON/OFF/TO 输入。尚未验证按周期更新时的延迟、未来数据可用性、漂移跟踪和实时置信度门控。

## 物理逆校正与 Production

估计值直接进入与 Stage2 零扩展线性插值相匹配的通道2逆递推；不是把估计值用于另一个理想化频域算子。F1 在所有 ON/OFF/TO 输入中保持不变。F2 相对 A0 的复 RMS：

| Seed | Role | 未校正 B | ON 候选校正后 | RMS 降幅 |
|---:|---|---:|---:|---:|
| 202 | ON / OFF / TO | 0.327884 / 0.316126 / 0.423032 | 0.072465 / 0.069490 / 0.096109 | 77.90% / 78.02% / 77.28% |
| 303 | ON / OFF / TO | 0.327964 / 0.317239 / 0.423158 | 0.104905 / 0.101039 / 0.138682 | 68.01% / 68.15% / 67.23% |

Known Correction 的复 RMS 小于 `1e-3`，所以 ON 候选只部分闭合到 A0。它仍在两 seed 的 Production 检测上恢复 `5/6` 目标机会；seed202 period1 的一个漏检与 A0/Known 相同，候选落在冻结 Doppler 门外。

实际 Native CUDA 使用 R7 二进制 SHA `de3026ed...`、`USE_COREX=OFF`。在线与固定标定各自的三角色归一化 runtime XML 指纹相同；6 个在线 ON/OFF/TO 分支全部通过 Production path gate，配套 CFAR map 数值审计也通过。

## 可部署状态

`PREVIOUSLY_EXECUTED=true`，`IMPLEMENTED=true`。`QUALIFIED_FOR_CURRENT_PRODUCTION` 仅适用于这两组 R8 输入上的固定二进制受控回放。`ONLINE_DEPLOYABLE=false`：

1. 估计量来自生产融合 F1/F2，而未知失配只注入物理通道2；融合相位斜率不等同于单通道物理时延的严格观测方程。
2. Stage2 线性插值频响不等于纯线性相位时延模型。
3. 估计使用完整三周期，同批校正是离线重放，不是单周期因果实时更新。
4. 没有校准的不确定度、可辨识性拒绝门、温漂/时变测试或真实设备数据。

因此，本轮证明“ON 数据可产生不读取 oracle 的确定性有效估计并可进入 R7 物理校正回放”，没有证明实时在线系统可部署，也没有证明 AI 有必要。
